Quorum API
Solução backend para rede social inspirada no X.

O Quorum é uma API desenvolvida para garantir a integridade e a interação do usuário. O foco do projeto é assegurar que as regras de negócio para atingir o "quórum" mínimo sejam respeitadas, utilizando uma arquitetura escalável e persistência de dados segura.

🎯 Diferenciais do Projeto
Validação de Regras: Lógica estruturada para fácil manutenção.

Integridade de Dados: Utilização de Migrations (Flyway) para controle rigoroso de versões do banco de dados.

Isolamento de Ambiente: Configuração completa via Docker Compose, facilitando o deploy e testes.

Segurança: Uso de JWT e 2Auth para proteção de dados.

🚀 Stack Tecnológica
Linguagem: Java 21+

Framework: Spring Boot 3.x / 4.0

Persistência: Spring Data JPA & Hibernate

Banco de Dados: MySQL 8.0

Infraestrutura: Docker & Docker Compose
